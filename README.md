# Calculadora Científica

Una calculadora científica completa y responsiva creada con HTML, CSS y JavaScript puro. No utiliza frameworks ni librerías externas.

## Características

- **Operaciones Básicas:** Suma, resta, multiplicación y división.
- **Operaciones Científicas:**
    - Exponenciación (`x²`, `x³`, `xʸ`)
    - Raíces (cuadrada `√`, cúbica `∛`)
    - Funciones Trigonométricas (seno, coseno, tangente y sus inversas)
    - Logaritmos (natural y base 10)
    - Constantes (π y e)
    - Factorial (`n!`)
    - Módulo (`%`)
- **Interfaz Moderna:**
    - Diseño minimalista y responsivo.
    - Modo claro y oscuro.
    - Animaciones sutiles en los botones.
- **Usabilidad:**
    - Entrada por teclado y clics.
    - Soporte para paréntesis en operaciones compuestas.
    - Visor con scroll horizontal para operaciones largas.
    - Botón para copiar el resultado al portapapeles.
    - Controles para borrar todo (`AC`) y borrar el último carácter (`C`).

## Uso

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/tu-usuario/calculadora-cientifica.git
    ```
2.  **Abrir `index.html`:**
    Navega al directorio del proyecto y abre el archivo `index.html` en tu navegador web.

## Estructura del Proyecto

-   `index.html`: Contiene la estructura HTML de la calculadora.
-   `style.css`: Define los estilos visuales, incluyendo el diseño responsivo y los temas claro/oscuro.
-   `script.js`: Implementa toda la lógica funcional de la calculadora.

## Controles del Teclado

-   **Números y Operadores:** `0-9`, `+`, `-`, `*`, `/`, `%`, `(`, `)`
-   **Calcular:** `Enter`
-   **Borrar último carácter:** `Backspace`
-   **Borrar todo:** `Escape`
